# 浏览器端加密分享页

一个可部署到 GitHub Pages 的纯静态加密分享工具。输入原文和密码后，页面会生成带密文的链接；接收者打开链接并输入密码，即可在浏览器本地解密。

## 特点

- 无后端、无数据库，适合静态托管。
- 密码不会写入分享链接。
- 使用 Web Crypto API 的 PBKDF2-SHA256 和 AES-GCM。
- 密文放在 URL Fragment 中，正常情况下不会随 HTTP 请求发送给服务器。
- 新链接使用混淆后的 “p2” 载荷格式，降低通讯软件自动扫描时的可读性。

## 本地运行

~~~bash
python -m http.server 8000
~~~

访问 “http://127.0.0.1:8000”。

## 部署到 GitHub Pages

1. 将文件推送到 GitHub 仓库。
2. 打开 “Settings → Pages”。
3. 选择 “Deploy from a branch”。
4. 选择默认分支和根目录，保存后等待部署完成。

## 安全说明

- URL 混淆不等于加密强度，安全性主要取决于密码。
- 原文最长 1000 个字符，避免生成过长链接。
- GitHub Pages、浏览器扩展、剪贴板历史和聊天软件仍可能接触链接本身。
- 不建议用于长期保存高敏感数据；重要内容应使用成熟的端到端加密工具。
